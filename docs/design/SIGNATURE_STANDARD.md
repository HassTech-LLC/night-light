# Night Light Signature Standard

The approved product default is a calm charcoal-and-amber desktop surface, based on the production concept rather than a marketing-only mockup.

- Dark: `#101217` page, `#191c22` panel, `#f3ad3d` accent, Frosted finish.
- Light: `#e8ebef` page, `#f7f3ea` panel, `#995b16` accent, Ceramic finish.
- A larger crescent and wordmark establish the product identity.
- Smart/Manual selection uses one unmistakable amber selected state.
- Adjustments, original-color preview, timeline, and expanded settings use calm grouped wells.
- Real output controls, Smart Mode behavior, labels, and information architecture remain unchanged.

Existing personal themes are preserved. Only the exact former blue Liquid factory pair is upgraded automatically. Reset this mode applies the new signature default for the active theme.
